# Final-Project
#### Video Demo:  <https://youtu.be/2lByKLG0Ai0>
#### Description: **Students Results Generator** is a command-line Python program that turns a list of student names and marks into an organized results report. It is designed to make a small classroom task easier to follow: enter each student’s information, check that the mark is valid, calculate the percentage, determine the result, and save the finished information in a file. The program also prints a neatly formatted table so the results can be reviewed immediately.

When the program starts, it creates a fresh `data.csv` file and writes a header row for the results. It then prompts the user to enter a student’s name and marks. Each entry is processed before the next student is entered. The name is cleaned up by removing surrounding spaces and capitalizing it, so an entry such as ` ali ` is displayed as `Ali`. Marks are converted to integers, and the program accepts only values from 0 through 65. If the input is not a valid number or falls outside that range, the program reports an error and asks the user to try again.

The user can enter results for several students in one session. Once all entries have been added, the user signals the end of input with Ctrl-D. The program then processes the students collected during that session. Each student receives a serial number, which helps distinguish rows in the report and keeps the records easy to scan. The marks are converted into percentages based on a maximum possible score of 65. The percentage is rounded to a whole number and displayed with a percent sign.

A separate pass/fail function evaluates the calculated percentage. A result of 50% or higher is marked **PASS**, while a result below 50% is marked **FAIL**. Another function assigns an emoji to match the outcome: a thumbs-up for a pass and a thumbs-down for a fail. Keeping these steps in separate functions makes the program’s rules easier to read and change. For example, the passing threshold or the displayed result could be updated without rewriting the code that collects student information.

After calculating the results, the program appends a row for each student to `data.csv`. Each row contains the student’s serial number, name, percentage, pass/fail result, and matching emoji. CSV is a simple format that can be opened in spreadsheet applications or a text editor, making the results portable and convenient to review. The program then reads the CSV file and uses the `tabulate` library to print the data as a clear, aligned table in the terminal.

The project brings together several useful Python concepts in one small application. It demonstrates how to collect input, handle end-of-input, convert text into numbers, validate a range, store related information, and use functions to divide work into clear steps. It also shows how Python’s built-in `csv` module can write structured data to a file, while an installable library such as `tabulate` can improve how that data is displayed.

The CSV file is recreated at the start of each run because the program opens it in write mode when creating the header. This means the file contains results from the latest run, rather than building a permanent history across multiple runs. That behavior keeps each session’s report straightforward, though users who want to preserve older results would need to change the file-handling approach.

Overall, Students Results Generator is a practical beginner project for converting raw marks into a readable summary. It combines input validation, percentage calculations, decision-making, file storage, and formatted output in a workflow that is easy to demonstrate. Its clear rules and modular functions also make it a useful starting point for future improvements, such as saving past sessions, supporting different maximum marks, or adding more report options.
